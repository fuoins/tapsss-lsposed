# 扫雷联萌增强（LSPosed 模块）

针对「扫雷联萌」（`com.star.minesweeping`，官网 <http://tapsss.com/>）的 LSPosed 模块。
适配版本：**3.6.10**（3.6.x 结构一致）。

## 下载

已构建的 APK：[v1.0.21 release](https://github.com/fuoins/tapsss-lsposed/releases/latest)
同一 release 还附带官方 3.6.10 的共存版 APK（`schulte-official-3.6.10-coexist.apk`，仅改包名、dex 类名不变、跳过签名校验），用于共存环境测试模块。

## 功能

### 舒尔特方格

> 模块设置里列出的都是模块新增的功能；App 自带的「开始倒计时」等设置保持原样，模块不再重复提供。

- **倒计时期间点击不直接开始（可关闭）**：倒计时进行中点击棋盘不会跳过倒计时直接开局，并弹提示；关闭后恢复 App 原行为。
- **右上角阶数弹窗增强**：点游戏右上角「阶数」按钮，弹窗内可同时切换 **官方模式**（简单 / 简单·盲打 / 普通 / 普通·盲打 / 混合·简单 / 混合）、**高级模式** 和 **阶数**（3–10）；底部还有「舒尔特设置」「模块设置」两个文字入口。
- **高级模式**（在**当前官方模式基础上**叠加出题顺序规则：简单 / 普通 / 打乱 / 盲玩都可叠加；成绩沿用**官方结算弹窗**，弹窗样式、新纪录与排名都与官方模式一致；弹窗标题显示「简单-顺序」「简单-倒序」「打乱-归中」这类高级模式标签；点空白处关闭面板会停留在上一把，左下角出现成绩图标，点它可以重新打开，只有面板里的「重开」才会开下一把；曲线 x 轴、提示框和「点击查看详细数据」列表的序号在倒序、归中下都按实际点击的数字显示）：
  - **顺序模式**：1→n²，等同官方普通模式；
  - **爆手速训练**：1→x（x ≤ 阶数²，可在弹窗内设置），点到 x 自动重开；点错**不重开**，只提示应该点哪个数；对局中改 x 也立即按新值生效；
  - **倒序训练**：n²→1；
  - **归中训练**：1→n²→2→n²-1→…；
  - **max≤N 训练**：除开局反应外，相邻两个数的最大间隔 ≤ N 秒，超时重开；N 可在弹窗内自定义（ms），留空用内置参考值（3阶 0.1 / 4阶 0.2 / 5阶 0.25 / 6阶 0.4 / 7阶 0.75 / 8阶 1.0 / 9阶 1.75 / 10阶 3.0）；
  - **1start 训练**：仅 3–5 阶，开局点 1 的反应必须 ≤ 0.45 秒（可在弹窗里自定义毫秒，留空用内置 450ms），否则重开。
  - 每个模式旁有 `i`，点击查看训练说明。
  - **点错提示**：点错时提示「点错了，应该点 N」，所有高级模式（含爆手速）都不因点错重开。
  - **音效 / 震动 / TTS 跟随 App 设置**：正确音、错误音、震动与「应该点 N」播报全部走 App 自己的回调，设置里关掉就一起关掉。
  - **简单 / 简单打乱下点过即消失**：与官方一致，点过的格子立即消失，且消失的**就是刚点的那一个**（倒序/归中同样正确）。结算弹窗出现时棋盘会还原成这一局最初的样子，点空白关闭弹窗后仍能看到完整的块（与官方顺序简单一致）。
- **非新纪录不展示成绩，自动下一把（可关闭）**：**官方模式与高级模式都生效**。每局结束若没刷新本地纪录，不显示成绩直接开始下一局。最佳纪录按 **官方模式（简单/普通/打乱/盲玩） × 高级模式 × 阶数** 分开计算（爆手速再按目标 x 分开）。规则失败提示（1start 超过反应上限 / max≤N 间隔超时）属于提示而非成绩，**不受该开关影响，始终显示**。某模式/阶数第一次打时会提示「已开启【非新纪录不展示成绩，自动下一把】功能，正在获取顺序下的记录数据」——排行数据由服务器异步返回，结算时还拿不到，那一把必然先按官方流程展示；模块会在这次结算时补装成绩弹窗拦截，并直接拦成绩 Dialog 的 show 兜底，所以同一个游戏页里的下一把起就静默，不再需要切一次模式。
- **切换高级模式立刻生效**：在阶数弹窗里点高级模式会直接关闭弹窗并按新模式重建本局；切换官方模式（简单/普通/打乱/盲玩）**不会**把高级模式退回「顺序」，高级模式始终叠加在当前官方模式之上。
- **设置返回即整页重建**：从「舒尔特设置」返回游戏页会直接重建页面，主题 / 倒计时 / 重开预设等所有设置立刻按新值生效，无需退出游戏页重进。
- **目标 x 跟随阶数**：爆手速的目标 x 上限随阶数实时更新，换到更小阶数时会压回新上限（n²）。
- **接管状态可见**：模式弹窗里「高级模式」右侧会显示当前版本与 Hook 接管状态（如 `v1.0.21 · 已接管·重读✓`），用来确认模块确实生效；每次回到游戏页还会补装一遍漏掉的 Hook，无需重启 App。
- **阶数显示跟随实际**：游戏内切过阶数后，再打开「模式与阶数」弹窗显示的是棋盘当前阶数，不再是进入游戏时的阶数。
- **倒计时取消下限限制**：舒尔特倒计时时长可设为 0（不等待），不再受 App 自带的毫秒下限限制。
- **重开预设（新增一键预设按钮）**：App 设置 → 舒尔特方格 → 重开，页面顶部新增「重开预设」按钮；弹窗里两条预设：「错一个就重开」把所有模式（简单 / 简单盲玩 / 普通 / 普通盲玩 / 简单打乱 / 打乱）× 所有阶数（3–10）的「错误自动重开」打开并把错误数设为 1，「错误不重开」则全部关闭并把错误数设为 0，确认后立即刷新页面。写入的 key 与官方一致（`type + true/false`、`type + true/false + level`），1.0.19 起修复了之前 key 拼错导致点了没效果的问题。
- **成绩曲线 x 轴按实际点击数收敛**：爆手速只点到 x 个（例如 x=1）时，曲线 x 轴不再画出大量重复数字，只按真实点数显示 1..x 的整数刻度。
- **今日统计显示高级模式记录**：成绩弹窗里的「今日统计」（次数 / 最佳 / 平均）改为统计模块本机的今日记录，高级模式不再显示为空（爆手速按目标 x 分开统计）。
- **本地记录页顶部标签**：本地记录页顶部（表头之上）新增「官方记录 / 高级模式」标签，选「高级模式」即切换为模块本机保存的高级模式记录（不上传服务器），不再放进「三个杠」抽屉。
- **排名页模式改为顶部滑栏标签**：排名页「三个杠」里的模式收纳改成和「总成绩 / 3×3 …」一样的横向滑栏（第一排官方模式、第二排高级模式），选中样式与官方标签一致（深色加粗 + 下划线）；选到高级模式时榜单只显示自己的本机记录（本地数据），且本地榜单面板从标签栏下方开始，不会盖住上面两排标签。

### 账号与登录

- **多设备掉线自动重登（默认开启）**：当同一账号在另一台设备登录、本机被踢回登录页时，自动填入上次保存的账号密码并提交登录。
- 登录提交时会自动保存账号密码；可在模块设置中清除。

## 安装

1. 安装模块 APK；
2. 在 LSPosed 管理器中启用「扫雷联萌增强」；
3. 作用域勾选 **扫雷联萌**（`com.star.minesweeping`）；共存包（`com.star.minesweepinh` 等 `com.star.minesweep*` 前缀）会一起出现在推荐列表里，勾选即可，模块按包名前缀接管；
4. 强制停止并重新打开扫雷联萌。

## 使用

进入扫雷联萌 → **设置** → 最顶部的 **模块设置** 区块：

- 舒尔特方格 / 账号与登录两个入口，右侧「…」打开完整菜单（含关于）；
- 舒尔特改动从设置页返回即生效；若模式弹窗显示「未接管」，请先在 LSPosed 里确认作用域已勾选，并强制停止后重开游戏。

## 构建

本地需要 Android SDK（platform 33 + build-tools 34）与 JDK 17：

```bash
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`

GitHub Actions 会自动构建并上传 APK（见 `.github/workflows/build.yml`）。

## 实现说明（适配 3.6.10，类名/字段名为反编译后的混淆名）

| 功能 | Hook 点 |
| --- | --- |
| 设置页入口 | `SettingActivity.init()` 后，在最顶部插入同级区块：标题「模块设置」+ 舒尔特方格 / 账号与登录 / 「…」，视图结构与 `activity_setting.xml` 里其它区块一致（`MenuTitleText` + `layout_selector_background_radius_4`） |
| 舒尔特功能页 | 设置页 `SettingSchulteStartActivity.init()` 后替换「倒计时时长」输入框的 NumberInterceptor 下限为 0（限舒尔特页生效）；功能开关/时长均跟随 App 自带设置 |
| 倒计时点击拦截 | `SchulteView.onTouchEvent` before：倒计时截止前吞掉 DOWN/POINTER_DOWN；同时拦 `j(null)` 兜底；开关来自模块设置 |
| 阶数弹窗 | `ActionBar.c(style, iconRes, listener)` after：`ic_game_level` 按钮换成 App 原生 `SquareSizeDialog`（`k.b.z3`），标题下插入官方模式 + 高级模式 + 目标 x，底部追加「舒尔特设置」「模块设置」文字按钮 |
| 高级模式 | `SchulteView.e(row,col)` before 完全接管点击（不触发官方 listener）；`SchulteView.j(cells=null)` after 记录开局（`SchulteStatus` 枚举常量名是 `Normal/Ready/Gaming/Finished`，判断状态必须用 `name()`，不能用混淆字段名 `b/c`）并开新一局；`SchulteView.i(null)` after 清空对局；`i.c.d.c.a.d(long)/b(int)` 屏蔽官方重开预设。结算**走官方**：把本局数据写回 `SchulteGameActivity$c` 用的 result helper（`timer.p` + `result.t/u/p`）与 game 状态，再调用 `i.c.a.e.s.z(true)`，因此弹窗、新纪录、排名与官方模式一致（新纪录/排名需登录且上传成功） |
| 官方模式非新纪录静默 | `SchulteGameActivity$b.d(int,int)` before：读计时器时间与 game 的阶数/类型/盲玩，与本模式本阶数的本地最好成绩比较；不是新纪录就 `setResult(null)` 跳过官方结算，150ms 后带 bypass 标记调 `V()` 自动下一把；`AdvancedSchulte.advCompleting` 避免高级模式自己的官方结算被二次拦截 |
| 重开预设 | `SettingSchulteRestartActivity.init()` after：在 ScrollView 内容顶部插入「一键配置预设」+「重开预设」按钮；确认后反射写 `i.f.j.i`（错误自动重开开关，key=type+blind）与 `i.f.j.j`（错误数，key=type+blind+level，3–10 阶全部设为 1），再调官方私有 `w(type, blind)` 刷新页面显示 |
| 快速开始入口 | 进程启动（`MinesweeperApplication.onCreate`）时把 `GameMenu("ic_setting","模块设置")` 写进快速开始列表（KV `utils.h.i`），并在「全部游戏」网格里注入同款格子；点格子可像其它游戏一样增删（`$b.p` 拦截 → 改 KV 列表 + 刷新）；点快速开始里的图标打开面板（`$a.p` 拦截 + `ActionRouter.go` 兜底） |
| 模式切换 | 改 `Intent` 的 `type`/`blind`/`level` extras 后 `recreate()`，让 ARouter 重新注入字段并重建模式控制器 `i.c.d.c.a`；只改阶数时仍调原 `W(int)`（用一次性标记绕过 `M()` 的「游戏进行中」判断） |
| 自动重登 | `LoginActivity.L()` before 保存手机号/密码；`LoginActivity.init()` after 自动填入并调用 `L()` |

配置保存在目标应用私有目录 `shared_prefs/tapsss_module.xml`（普通 `SharedPreferences`，Hook 与被 Hook 同进程）。

## 注意

- 目前只做了**舒尔特方格**一个游戏的选项，其他游戏入口后续可扩展。
- 模块基于 3.6.10 的混淆结构；若 App 大版本更新导致类名/字段变化，Hook 会静默失效（日志 TAG：`TapsssModule`），需要重新适配。
- 保存的密码以明文存放在扫雷联萌的私有 SharedPreferences 中，仅供自动重登使用；介意的话请在模块设置里清除。
- 仅供学习交流，请遵守目标软件的服务条款。
