## 安装

**① 下载模块** —— [最新 Release](https://github.com/fuoins/tapsss-lsposed/releases/latest) 里的 `tapsss-x.x.x.apk`。

**② 在 LSPosed 里启用** —— 安装后打开 LSPosed 管理器，勾选「扫雷联萌增强」。

**③ 勾作用域** —— 作用域选中 **扫雷联萌**（`com.star.minesweeping`）。共存包（`com.star.minesweepinh` 等 `com.star.minesweep*` 前缀）会一起出现在推荐列表里，模块按包名前缀接管。

**④ 重启目标应用** —— 强制停止扫雷联萌再打开。进入 **设置** 页，最顶部会出现「模块设置」区块，说明生效。

> 需要共存环境测试？官方 3.6.10 共存版 APK（`schulte-official-3.6.10-coexist.apk`，仅改包名、dex 类名不变、跳过签名校验）在 [v1.0.21 Release](https://github.com/fuoins/tapsss-lsposed/releases/tag/v1.0.21) 里。

## 功能

模块设置页分三个入口：**舒尔特方格** / **2048** / **账号与登录**，右侧「…」展开完整菜单（含关于）。舒尔特的改动从设置页返回即生效。

### 舒尔特方格

> 模块设置里列出的都是模块**新增**的能力。App 自带的「开始倒计时」等设置保持原样，模块不重复提供。

#### 模式与阶数弹窗

点游戏右上角的「阶数」按钮，原来的弹窗会变成三段式：

- **官方模式**：简单 / 简单·盲打 / 普通 / 普通·盲打 / 混合·简单 / 混合
- **高级模式**：8 种，见下表
- **阶数**：3–10

弹窗里的所有选择（官方模式、高级模式、阶数、x / 区间参数）都是**暂存**，点最底部的「确认」才生效并关闭面板；底部另有「舒尔特设置」「模块设置」两个文字入口，点了直接跳页面。

#### 八种高级模式

高级模式是在**当前官方模式的基础上**叠加出题顺序规则——简单、普通、打乱、盲玩都能叠。

| 模式 | 出题规则 | 结束条件 |
| :--- | :--- | :--- |
| **顺序** | 1 → n² | 等同官方普通模式 |
| **爆手速训练** | 1 → x（x ≤ n²，弹窗内可设） | 点到 x 自动重开；点错**不重开**，只提示该点哪个数 |
| **倒序训练** | n² → 1 | 点完即结算 |
| **归中训练** | 1 → n² → 2 → n²−1 → … | 点完即结算 |
| **max≤N 训练** | 相邻两数间隔 ≤ N 秒 | 超时重开。N 可自定义（ms），留空用内置参考值 |
| **1start 训练** | 开局点 1 的反应 ≤ 0.45 s | 超时重开，仅 3–5 阶 |
| **顺序区间** | 只点 `[起点, 终点]` 递增区间 | 起点 < 终点 ≤ n²，留空为 1 / n² |
| **倒序区间** | 只点 `[起点, 终点]` 递减区间 | 终点 < 起点 ≤ n²，留空为 n² / 1 |

`max≤N` 的内置参考值（留空时生效）：

| 阶数 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 10 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| N（秒） | 0.1 | 0.2 | 0.25 | 0.4 | 0.75 | 1.0 | 1.75 | 3.0 |

几个共通行为：

- 成绩**沿用官方结算弹窗**，样式、新纪录、排名都与官方模式一致，标题会显示「简单-顺序」「简单-倒序」「打乱-归中」这类标签。
- 对局中点空白处关闭面板，会停留在上一把，左下角出现成绩图标，点它可以重新打开；只有面板里的「重开」才开下一把。
- **点错提示**：提示「点错了，应该点 N」，所有高级模式（含爆手速）都不因点错重开。
- **音效 / 震动 / TTS 跟随 App 设置**：正确音、错误音、震动和「应该点 N」播报都走 App 自己的回调，设置里关掉就一起关掉。
- **简单 / 简单打乱下点过即消失**：与官方一致，点过的格子立即消失，且消失的就是刚点的那一个（倒序、归中同样正确）。结算弹窗出现时棋盘还原成这一局最初的样子，关闭弹窗后仍能看到完整的块。
- 每个模式旁有 `i`，点击查看该模式的训练说明。

#### 结算与记录

**非新纪录不展示成绩，自动下一把（可关闭）** —— 官方模式和高级模式都生效。每局结束若没刷新本地纪录，不显示成绩直接开下一把。

- 最佳纪录按 **官方模式（简单 / 普通 / 打乱 / 盲玩）× 高级模式 × 阶数** 分开计算，爆手速再按目标 x 分开。
- 规则失败提示（1start 超反应上限、max≤N 间隔超时）属于**提示**而非成绩，不受该开关影响，始终显示。
- 某模式 / 阶数第一次打时会提示「已开启【非新纪录不展示成绩，自动下一把】功能，正在获取顺序下的记录数据」——排行数据由服务器异步返回，结算时还拿不到，那一把必然先走官方流程。模块会在这次结算时补装拦截，并直接拦住成绩 Dialog 的 `show`，所以同一个游戏页里的下一把起就静默，不用再切一次模式。

其余记录相关改动：

| 位置 | 变化 |
| :--- | :--- |
| 成绩弹窗 → 今日统计 | 改为统计**本机**今日记录，高级模式不再为空（爆手速按目标 x 分开） |
| 本地记录页 | 表头之上新增「官方记录 / 高级模式」标签，高级模式记录不上传服务器 |
| 排名页 | 「三个杠」里的模式收纳改成横向滑栏标签（第一排官方、第二排高级），选中样式与官方一致；高级模式榜单只显示本机记录，且面板从标签栏下方开始，不遮住标签 |
| 成绩曲线 x 轴 | 按**实际点击数**收敛。爆手速只画 1..x，区间模式按「起点→终点」画刻度；关闭面板后重新打开仍是这一把，序号不会退回 1..n² |

#### 交互细节

| 行为 | 说明 |
| :--- | :--- |
| 倒计时期间点击不直接开始（可关闭） | 倒计时中点击棋盘不会跳过倒计时，改为弹提示；关闭后恢复 App 原行为 |
| 倒计时下限取消 | 舒尔特倒计时可设为 0（不等待），不再受 App 自带毫秒下限限制 |
| 确认后立刻生效 | 选完模式 / 阶数点「确认」直接重建本局；只改区间参数也会重开让新区间生效。切官方模式**不会**把高级模式退回「顺序」 |
| 设置返回即整页重建 | 从「舒尔特设置」返回游戏页会重建页面，主题、倒计时、重开预设立刻按新值生效，不用退出重进 |
| 阶数显示跟随实际 | 游戏内切过阶数后，再开弹窗显示的是棋盘**当前**阶数，不是进入时的阶数 |
| 目标 x 跟随阶数 | 爆手速的 x 上限随阶数实时更新，换到更小阶数时压回新上限（n²），对局中改 x 立即生效 |
| 接管状态可见 | 弹窗里「高级模式」右侧显示版本与 Hook 状态（如 `v1.0.24 · 已接管·重读✓`）；每次回到游戏页还会补装一次漏掉的 Hook，不用重启 |
| 快速开始加捐赠入口 | 设置 → 快速开始默认多一个「捐赠」格子（支付宝图标），点了用浏览器打开捐赠页；和「模块设置」格子一样可自行删除，删掉不会被塞回 |

#### 重开与预设

**重开页顶部两排模式标签** —— App 设置 → 舒尔特方格 → 重开，原来的「右上角模式选择」换成两排横向滑栏：

- 第一排：官方模式（简单 / 简单盲玩 / 普通 / 盲玩 / 简单打乱 / 打乱）
- 第二排：高级模式（顺序 / 爆手速 / 倒序 / 归中 / max≤N / 1start / 顺序区间 / 倒序区间）

选「顺序」时下方就是官方配置；选某个高级模式时，下方**仍然是官方那套「重开时错误」界面**（开关 + 3×3～10×10 阶数条目），只是读写的数据换成该高级模式自己的（存在 `adv<模式>_<阶数>`），与顺序模式互不影响。高级模式里点错时，开了「错误自动重开」就按对应阶数的错误数阈值重开，没开则只提示该点几。

**重开预设（一键配置）** —— 重开页顶部新增「重开预设」按钮，弹窗里有四个预设：

| 预设 | 作用范围 |
| :--- | :--- |
| 错一个就重开（所有模式 · 顺序） | 官方 6 模式 × 3–10 阶，全部打开「错误自动重开」并把错误数设为 1 |
| 错一个就重开（爆手速 / 倒序 / 归中 / max≤N / 1start / 顺序区间 / 倒序区间） | 分别为对应高级模式打开并设为 1 |
| 错一个就重开（所有模式 · 所有高级模式） | 一次覆盖官方 6 模式 + 全部 8 个高级模式 |
| 错误不重开（所有模式 · 顺序） | 全部关闭并把错误数设为 0 |

确认后立即刷新页面。写入的 key 与官方一致（`type + true/false`、`type + true/false + level`）。1.0.19 起修复了之前 key 拼错导致点了没效果的问题。

### 2048

#### 尺寸与难度

右上角「难度」弹窗从原来的三个按钮换成 **4×2 方格**，覆盖 3×3 – 10×10 共 8 档，每格底部标注该尺寸的目标分数（规则：每升一阶 ×8）。

| 尺寸 | 3×3 | 4×4 | 5×5 | 6×6 | 7×7 | 8×8 | 9×9 | 10×10 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 目标分 | 256 | 2,048 | 16,384 | 131,072 | 1,048,576 | 8,388,608 | 67,108,864 | 536,870,912 |

方格下方另有「自定义」入口，行、列都可在 3–10 之间任选（支持矩形，如 3×7），目标分数按**较短边**计算，规则同上。

弹窗底部新增两个胶囊按钮：「2048设置」打开 App 官方的 2048 设置页，「模块设置」打开模块自己的设置页（样式与舒尔特弹窗底部入口一致）。

#### 撤销

游戏底栏右侧新增「撤销」按钮，回退上一步（恢复棋盘、分数与随机种子），可无限次使用。

**只要本局用过撤销，结束时只在本地记录成绩，不上传服务器**，首次点击会提示一次。撤销栈只对当前页面有效，真正开新局（该尺寸读到空存档）时才清空该尺寸的撤销标记。

撤销标记按棋盘尺寸分档（方形 = 边长，自定义 = 行×列），和官方存档一一对应：

- 玩 3×3 撤销后切到别的尺寸，再切回 3×3 恢复那一档存档，仍然保持「不上传」；
- 只有某一档读到空存档（真正开新局）时才清除该档标记。

早先标记只有一个全局开关，切尺寸就会清掉，导致切回旧尺寸恢复存档后又被上传——该问题已修复。

**撤销后不再掉登录**：本局用过撤销，即使退出重进、从设置返回重建、进程被杀后从存档恢复，都只在本地留记录，成绩弹窗不再显示登录入口。之前恢复存档时标记会被清掉，上传了一份与撤销后棋盘不一致的动作记录，服务器返回登录失效，表现为「撤销后偶尔直接掉登录」。

#### 结算与显示

| 改动 | 说明 |
| :--- | :--- |
| 从「2048设置」返回即整页重建 | 打开官方 2048 设置（显示 / 触控 / 摇杆）返回后整页重建，设置立刻生效。重建前先把当前棋局写进官方存档，返回后原样恢复；同时把当前尺寸写回 Intent，避免从排行榜按旧尺寸进入、中途换过尺寸时恢复错档 |
| 模块设置新增 2048 入口 | 设置 → 模块设置 → 2048，可看功能说明、目标分数换算示例，并可跳转官方 2048 设置页 |
| 成绩面板适配 | 结算弹窗的标题、目标值、时间按实际行列（含矩形与 6–10 阶）正确计算 |
| 排行榜适配 | 每个尺寸一个主标签（3×3 – 10×10 共 8 个，横向滑动），「时间 / 分数」作为同尺寸下的一排子标签，切尺寸与切榜单类型互不干扰 |

### 账号与登录

- **多设备掉线自动重登（默认开启）**：同一账号在另一台设备登录、本机被踢回登录页时，自动填入上次保存的账号密码并提交登录。
- 登录提交时自动保存账号密码，可在模块设置中清除。

## 兼容性

| 项目 | 要求 |
| :--- | :--- |
| Android | 5.0+（`minSdk 21`，`targetSdk 33`） |
| 框架 | LSPosed（基于 Xposed API） |
| 目标应用 | 扫雷联萌 **3.6.10**，3.6.x 结构一致 |
| 共存包 | `com.star.minesweep*` 前缀，模块按前缀接管 |
| 架构 | 依赖目标 App 的混淆类名，**App 大版本更新后可能静默失效** |

模块基于 3.6.10 的反编译结构实现。若 App 大版本更新导致类名 / 字段变化，Hook 会失效——日志 TAG 为 `TapsssModule`，可在 LSPosed 日志里过滤。目前覆盖**舒尔特方格**与 **2048** 两个游戏，其他游戏入口后续可扩展。

## 从源码构建

需要 JDK 17 与 Android SDK（platform 33 + build-tools 34）：

```bash
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`。

推送到 `main` 或手动触发 `workflow_dispatch` 时，GitHub Actions 会自动构建并上传 APK（见 [`.github/workflows/build.yml`](.github/workflows/build.yml)）。

## 常见问题

<details>
<summary><b>弹窗里显示「未接管」怎么办？</b></summary>

<br>

先确认 LSPosed 里作用域已经勾选 `com.star.minesweeping`（共存包勾对应的包名），然后强制停止扫雷联萌再打开。模块每次进入游戏页会补装一次漏掉的 Hook，多数情况下不用重启手机。

</details>

<details>
<summary><b>App 更新后功能全没了？</b></summary>

<br>

模块是按 3.6.10 的混淆结构写死的。App 大版本更新后类名 / 字段可能变化，Hook 会静默失效（不会崩溃）。等模块适配新版本，或先退回 3.6.x。

</details>

<details>
<summary><b>用了撤销，成绩没上传，是 bug 吗？</b></summary>

<br>

是设计如此。撤销会改变动作序列，和服务器上的排行数据对不上，所以用过撤销的这一局只在本地记录。想上传就别点撤销。

</details>

<details>
<summary><b>密码明文保存安全吗？</b></summary>

<br>

模块把账号密码存在扫雷联萌的**私有** SharedPreferences 里（`/data/data/<包名>/shared_prefs/`），仅供自动重登使用，其它应用读不到（除非有 root）。介意的话在模块设置里清除，或关掉自动重登。

</details>
